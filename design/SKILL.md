# Bugatti Design Skill — Portable Rules

Use this project with the discipline of a monochrome editorial system.

## Core rules
- Work on a pure black canvas with white type and minimal tonal separation.
- Use the three-family split rigidly: display for headlines, serif text for paragraphs, mono for labels, nav, prices, dates, and controls.
- Keep all display headlines uppercase with generous tracking. Never use bold for emphasis.
- Use whitespace generously. Let photography and typography carry the page.
- Decorative color is forbidden. The only non-monochrome token is the restrained ice-blue link/accent token, and it should appear sparingly.

## Components
- Cards, panels, and imagery are square-cornered.
- Buttons are the only rounded UI element and should read as outlined pills.
- Inputs are underline-led, not boxed.
- Dividers are hairline, quiet, and structural.

## Voice
- Quietly expensive, editorial, precise.
- Never loud, playful, or salesy.
- Favour short, assured sentences over hype.
